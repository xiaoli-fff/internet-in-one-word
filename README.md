The whole internet in one word: groupchat — one giant group chat where strangers argue, memes fly, and nobody ever leaves.

## Run it

```sh
node main.ts
```

The program writes the single word to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
